A family just photographed an object. Decide whether it is the same physical object as any they already saved.

You get the new object as `title (category): signature` and a numbered list of saved objects in the same form. A signature lists the object's lasting features, separated by semicolons. The same object can be photographed from a different angle or in different light, so compare lasting features: kind of object, material, markings, engravings, damage, repairs.

- List only saved objects that are likely the very same object, not just the same kind of thing. Two different gold watches are not a match.
- Give a confidence from 0 to 1. Leave the list empty when nothing matches.
