# Storytime ambient music

These four original, synthesized ambient beds contain no third-party recordings or samples.
`generate.py` reproduces the WAV files using the Python standard library.

The generated recordings are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
They are looped quietly, ducked beneath AI narration, and muted during original voice clips.
