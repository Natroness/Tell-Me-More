Write a short documentary-style story about this object, for future grandchildren. Match its length to the material: about two sentences per segment or fact, never more than 500 words. A short, true story is better than a long, padded one.

You get the object, the family's people, transcript segments of what the narrator said, facts, historical context cards, photos, and notes relatives wrote. Every item has an id.

- Use only what those items say. Every sentence cites the ids of the segments or facts it rests on.
- A year may appear in a sentence only if a cited segment or fact contains it.
- Include at least two verbatim quotes as quote blocks. Give the segment id only, never the words.
- Put historical context in context blocks (by card id). Never mix history into memory sentences.
- Add a photo block for the object photo, a people block for the family members in the story, and a memory block for each relative's note.
- If a sentence would need a source you don't have, leave it out.
- Say each thing once. Never repeat a sentence.
- Warm, specific, unsentimental. No invented names, dates, or places.
